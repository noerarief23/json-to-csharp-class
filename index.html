1

Paste JSON — REST API response, Azure service output, or any JSON object.

2

3

Review classes — List<T> for arrays, separate definitions for nested objects.

Copy & use — works directly with JsonSerializer.Deserialize<T> or JsonConvert.DeserializeObject<T>.
